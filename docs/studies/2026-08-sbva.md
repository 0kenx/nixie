# Structured BVA (established-candidates Priority 4): sound slice landed opt-in, corpus-negative beyond the band — default off (2026-08-23)

## Pre-registration

The established-candidates doc's Priority 4 first slice: production
structured candidate generation (the doc calls the existing
`Preprocessor::bounded_variable_addition` a dead, pairwise routine), one-shot
pre-search non-incremental CNF, no attached theory, no proof tracer,
equisatisfiable by construction, reconstruction record — and the doc's
matched-null requirement: "introduce the same number and shape of
variables with candidate semantics scrambled. Do not infer value from raw
BVA-versus-baseline alone."

## What was implemented

`oxiz-sat/src/solver/bva.rs` — `Solver::structured_bva`, wired in
`solve()` pre-search behind `enable_sbva` (default off; `OXIZ_SBVA=1`
knob; `OXIZ_SBVA_NULL=1` for the null arm, the `OXIZ_PROBE_NULL`
precedent — same generation, budgets and application code, scrambled
processing order).

* **k-way common-literal-set extraction**: pair index over original
  clauses (3–24 literals), `G` = full intersection of a pair's group,
  benefit rule `saving = (k−1)·|G| − (k+1) > 0` (the published rule the
  dead pairwise routine lacked — it required `|G| ≥ 4` at k=2 and could
  never merge three clauses).
* **Encoding**: replace each `C_i = G ∪ U_i` by `(G ∨ t)` and `(¬t ∨
  U_i)`s — polarity-optimized Tseitin of `G ∨ (U_1 ∧ … ∧ U_k)`.
  Equisatisfiable AND model-preserving in both directions (proof in the
  module doc), so **no reconstruction record is needed**: a model of the
  rewritten formula is directly a model of the original.
* Slice gates: level 0, base scope, no theory, no DRAT/LRAT (introduced
  clauses have no derivation story — deferred, not TODO'd away), budgets
  (100k introductions, 8M pair-index entries).

## Results

* **Soundness: clean.**  Differential fuzz (30 000 random CNFs, spine-pool
  generator to make mergeable groups dense): 0 verdict mismatches, 0
  invalid models (every SAT model validated against the *original*
  clauses), introductions confirmed to trigger.  Full suite (10 072),
  clippy/fmt/doc, Z3 parity 168/168.
* **Corpus: NEGATIVE, beyond the ±5% band.**  94 files, both-solve cells
  (n=65), instructions-to-verdict:
  * SBVA arm: geomean(off/sbva) = **0.9295** (7% slower — outside the
    band; a real cost, not noise).
  * Matched null: geomean(off/null) = **0.9476** — nearly the same loss
    with the rank semantics scrambled.
  * Treatment ≈ null ⇒ **the harm is the introductions themselves, not
    the selection**.  54 of 94 files received introductions; the added
    variables (heuristic tables, decision space) and added clauses cost
    more than the merges save on this corpus — which already runs BVE+ELS
    by default, plausibly consuming the shared structure BVA would
    exploit.
  * The 6 verdict changes across arms at a 30 s cap are all
    timeout-boundary artifacts (SAT↔TO); no wrong answer vs the reference
    verdicts.

**Verdict: `enable_sbva` stays default-off; the slice lands as opt-in
infrastructure** with the fuzz as its regression guard.  This mirrors the
SOI disposition: sound, measured, not a default.

## What would change the verdict (recorded for the retry)

The corpus runs elimination by default; BVA's classic domain (CryptoMiniSat
experience) is structure-heavy inputs where aux variables *shrink the
formula massively* — multiplier/equivalence circuits.  A retry worth its
cost would (a) target QF_BV-derived CNF rather than the general corpus,
(b) gate on a *measured* formula-size reduction threshold (skip the
introduction unless it shrinks literal count by ≥ X%), and (c) interleave
with elimination rather than run after its fixpoint.  The infrastructure
is now in place to test each of those cheaply.

## Measurement note

The fuzz generator initially spun forever (rejection sampling a len-9
clause over 5 vars — a clause cannot exceed one literal per variable).
Diagnosed by per-iteration instrumentation after the dumped "hang" file
failed to reproduce standalone (the file was the *previous* iteration's —
the write precedes the hang).  Same lesson family as the orphan-harness
incidents: the reproducing artifact must be captured *at* the fault, not
before it.
