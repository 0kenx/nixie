# Binary extension affine solving: preregistration

The previous final source `260c0728` spends 13.138 times Z3's instructions
on the two-variable F256 square case and exhausts its unchanged work budget
on the depth-16 variant. Those expressions are affine over F2. Repeated
Cartesian enumeration, rather than genuinely nonlinear algebra, causes this
gap. The earlier instruction profile and current implementation establish
that each assignment rebuilds the exact evaluator's term cache.

Candidate: recognize constants, variables, addition, negation, bitsum,
constant multiplication and squaring of affine expressions over F2. Expand
these into binary coefficient equations and solve by exact XOR Gaussian
elimination. Never linearize a product of unequal nonconstant expressions.
Keep the existing total 22-bit assignment-space bound, independent model
validation, nonlinear enumeration fallback and proof-mode restrictions.
Charge translation and elimination against the same per-check work budget;
no wall-clock policy or uncharged speculative fallback. This is an exact
algebraic decision procedure, not a branching heuristic; enumeration is the
semantic control. No randomized search-policy claim is made.

References consulted before implementation:
- [NTL mat_GF2 Gaussian elimination interface](https://libntl.org/doc/mat_GF2.cpp.html)
  and [reference implementation](https://sources.debian.org/src/ntl/10.5.0-2/src/mat_GF2.cpp/).
- [Taverne et al., section 2.2](https://cacr.uwaterloo.ca/techreports/2011/cacr2011-07.pdf):
  squaring is linear in the polynomial-basis binary coefficients.
- Nixie's prime-field connected-component path and cvc5's `ff/parse.cpp`
  were inspected; splitting independent components alone would not address
  coupled affine systems. Z3's existing benchmark encoding already uses
  the F2-linear squaring map, so the reference is not artificially weakened.

Measurement plan, fixed before implementation/cost collection: CPU 0,
whole-process `instructions:u`, >=99% counter coverage, 120-second external
cap, initial seeds 0..9 and fresh seeds 10..19. Use exact independently
checked models. Unknown is unsolved, never a match. Reuse stored cells where
binary, input and invocation agree. Keep the earlier benchmark frozen;
add a separate affine suite including independent depth-1/depth-16 cases,
coupled square/constant-multiple systems, rank-deficient SAT and inconsistent
UNSAT systems, both F8 representations, and nonlinear/disequality controls.
The budget case must request a model so a newly decisive SAT can be checked.
Use installed Z3 4.16.0 with its existing exact BV squaring/multiplication
encoding. Record input, binary and harness hashes through benchstore.

Go/no-go in both seed sets: no wrong answers or lost previously solved cases;
all targeted affine cases decided; jointly solved hard affine instruction
geomean <=0.25 of baseline and <=1.0 of Z3; nonlinear and other controls
within 5% (neutral band). Report solved counts separately, full per-case
min/median/max distributions, and any rejection/timeout. Exhaustive tiny
field/matrix tests, planted coupled models, unsupported-product fallbacks,
budget exhaustion, certified-mode and scope tests precede all repository
release gates. Failed experiments will be recorded rather than erased.

## Implementation and independent audit

Source `a84f7a2e` adds a local affine encoder and augmented binary row
elimination. Each column is a field coefficient multiplying one input bit;
column zero is the constant. Addition is column XOR. Squaring squares the
coefficients, while multiplication by a constant scales them. Flattened
products are recognized only if their nonconstant factors have the same
affine map and occur a power-of-two number of times. Unequal factors and
other exponents decline to enumeration. No polynomial over a prime field
is reused for extension arithmetic.

Rows pivot on their lowest coefficient bit. XOR preserves their solution
set; a zero coefficient row with RHS one proves inconsistency. Reverse
substitution with free bits zero constructs a field model. The exact AST
validator checks that model; certified SAT additionally uses core's
independent convolution/division evaluator. Arithmetic UNSAT retains no
exported certificate and therefore still declines in certified mode.

The 34 focused tests pass. Independent coverage includes all three-row
binary matrices through three columns, every tiny-field assignment for the
affine expression operations against core's independent evaluator, all
coupled quadratic/linear F4 systems against explicit coefficient-array
exhaustion, the existing exhaustive quadratic-root tests in F4/F8/F16,
both F8 representations, and independently planted coupled AES-field
models. Additional checks cover every one of the 22 allowed input bits,
exact budget exhaustion, nonlinear/odd-power and disequality fallbacks,
and certified push/pop restoration. Encoder caches and row state are local
to each check, so no new scope state or certificate replay rules are added.

The shared budget covers the affine attempt and any enumeration fallback;
unsupported translation does not reset it. The original total assignment
space cap is checked before this path. Wide ground arithmetic and prime
solving are unchanged. This optimization does not claim general polynomial
solving or support for larger symbolic extension-field domains.

## Baseline and reference collection

The frozen corpus contains six hard and seven control families, each at
20 seeds. The prior Nixie binary decides **200/260** (180 SAT, 20 UNSAT,
60 Unknown). Z3 **4.16.0** decides **260/260** (240 SAT, 20 UNSAT).
Existing exact legacy invocations and identical certified reference labels
are reused, with explicit record aliases. No reference cell is rerun for
a different label. All new SAT results must pass independent evaluation;
the inconsistent family is proved empty by exhaustive coefficient images.
The new release binary's seed-zero functional preflight passes all 13
families, including certified coupled depth 16; this is functional evidence,
not a timing or instruction measurement.


## Isolated candidate measurements

The [full distributions](2026-09-23-ff-affine.csv) record both seed sets
for `a84f7a2e`. All **260 cases are decided** (240 SAT, 20 UNSAT), closing
all 60 baseline Unknowns without losing any previously solved case. Every
SAT model is independently evaluated; all decisive answers agree with Z3.
Both preregistered gates pass.

On hard cases jointly solved with the baseline, candidate/baseline
instruction geomeans are **0.009425 / 0.009202** (initial/fresh), or roughly
99.1% less work. Baseline Unknowns are excluded from these ratios. Across
all hard cases, candidate/Z3 ratios are **0.07324 / 0.08739**. The original
F256 pair goes from 13.138 times Z3's cost to **0.1516 / 0.1511**; the
formerly budget-limited independent case is now solved at **0.06410 /
0.06407** of Z3's instructions. Coupled depth 16 also improves, at
**0.02736 / 0.04660** of Z3. Nonlinear/disequality controls stay within
0.4% of baseline; prime/wide controls are also within 0.4%, in the neutral
band. These are whole-CLI instruction comparisons on this generated affine
fragment, not wall-time or general SMT superiority claims.

The old benchmark remains frozen, including its historical expectation of
Unknown on the budget case. The new suite requests that case's model and
validates the now-decisive result. Existing exact invocations are aliases,
not new measurements. All **2,940 canonical FF records** (old and new
suites combined) pass schema, record identity, path and uniqueness checks.
