## Ranked opportunities

1. **LIA LP bound propagation (structural, biggest payoff).**  wisa2
   signature: nixie 100k decisions / 53 conflicts (search starved of
   conflicts) vs Z3 141 conflicts / 382 decisions with
   `arith-bound-propagations-lp 2370`.  nixie's channel
   (`derive_arith_bound_propagations`) is gated to `QF_UFIDL`
   (`is_dl_family`) because its derived reasons are *incomplete Farkas
   justifications* on dense logics — an unsound propagation clause.  A probe
   (gate hacked open, unlandable) fired the channel on QF_LIA: it converts
   nec-smt `config_read_line` TO→7.3 s `unsat` and the small rings, but
   wisa-class stays TO — the per-assignment + memo shape (3.9 M calls, 388
   props fired once, then the memo blocks everything until an atom is
   asserted) is the wrong shape vs Z3's row-driven propagation at each
   arith check.  **Work item:** row-driven propagation off tableau rows
   with Farkas-complete reason collection — reference Z3
   `smt/theory_arith.*` bound propagation (`assert_bound` → row scan →
   `bound_evidence` with Farkas coefficients), then widen `is_dl_family`
   per-fragment as reasons are proven complete.  This covers most of the
   156-instance QF_LIA gap (wisa, rings, bofill, convert, pb2010,
   c_inference, ezsmt, Dartagnan, miplib, nec-smt, CAV/dillig stragglers).
2. **`ENCODE_DEPTH_LIMIT = 512` honesty-gates deep ite chains.**  nec-smt
   med/* (756-deep ite chains): **0 decisions, instant `unknown`**; Z3
   0.2–1.4 s.  Probe with the limit at 20000: prp-2-26 encodes and searches

## Implementation round (2026-11-12, same day)

**Item 2 (deep encode) — LANDED, `2d2653d3`.**  The CLI now runs on a
1 GiB stack worker (`NIXIE_STACK_MB` override) and opts into a 32768-deep
encoder cap via `set_encode_depth_limit`; the library default stays 512
(the cap protects NATIVE recursion, so raising it is a per-process stack
contract — the 1 MiB-stack regression test pins the default).  The
nec-smt instant-`unknown` class now reaches a real search.

**Item 1 (LIA LP propagation) — REVERTED as unsound-in-current-shape,
`77733f6a` records the negative result.**  Two landed prerequisites:
`d5fdbd98` completes the reason sets (tracker single-atom + simplex
`all_reasons()` on the fallback, replacing the both-sides aux shotgun —
counters bit-identical on the DL canaries), and `77733f6a` adds the
`NIXIE_APROP_VERIFY` push-time oracle (scoped LP probe: rows + negated
forced literal) plus branch-local bound rejection.  The widening itself
(QF_IDL/QF_LIA) flipped convert-jpg2gif-1552/1579 to **false `unsat`**
(z3 + pre-widening both `sat`); the oracle caught 198 invalid clauses on
one instance, including single-reason one-term clauses the live rows
cannot explain — the VALUE derivation reads conditional state as global
on dense logics (ite-column pins and friends).  `STATS` gained
`theory_props=`: the channel does fire on LIA once ungated (72k props /
50k decisions on bofill; conflicts 13→46), so the design direction is
right and the blocker is precise: make the oracle run clean before
re-widening (`6b749724` refined this - see below).  Net solve-rate at
the attempt: +9/−5 on the 70-instance
sample — irrelevant next to a wrong answer.

**Root cause #1 found and fixed: i64-wrapping accumulation.**  A term
printer (`nixie-core/src/ast/pp.rs`, explicit-stack, with
`collect_var_names`) lets `NIXIE_APROP_VERIFY=2` reconstruct every pushed
clause as SMT-LIB and classify it with z3.  Well-formed classification of
convert-1552: 16 of 198 flagged clauses GENUINELY invalid — all one shape:
atoms over expressions mixing ~4.3e9 bounds against ~1.8e19 coefficients,
where `lo_val += bv * coef` WRAPPED i64 silently in release (the products
reach 7.9e28).  The wrapped value fabricated the very bound being
derived; DL never saw it (±1 coefficients).  Fixed with
`checked_scale_add` (checked mul+add on both DeltaRational components;
overflow declines the derivation).  After the fix, convert-1552 answers
`sat`; convert-1579 still flips, and 50 of 229 flagged clauses remain
genuinely invalid — the remaining shape is multi-term derivations over
derived/transitive bounds (pinned vars carrying DIFFERENT per-side reason
sets; δ-strict encoding under suspicion).  The value-level TRACE
(`debug_derive_trace`: per-term side, value, reason ids) makes each of
the 50 hand-decidable; the gate stays QF_UFIDL-only until they are zero.

**Oracle refinement (`6b749724`).**  Decoding the flagged clauses
term-by-term found the scoped-LP oracle conflating *reason rows imply*
with *reason atoms imply*: asserted atoms like `(<= 2 z69)` record their
tracker bounds (`z69 >= 2`, reason intact) while the corresponding
simplex rows are ABSENT (dump state `tr_lo=2, sx=None`), so
semantically-valid clauses read as INVALID.  The sampled clauses decode
as valid implications; the false-`unsat` generator is still unfenced.
Two precise candidate defects now stand: (1) the tracker/LP divergence
itself — bounds without rows on QF_LIA, worth an independent audit —
and (2) a genuinely-invalid clause shape the row-based oracle cannot
isolate.  Next dig needs a term printer in `TermManager` to reconstruct
each pushed clause exactly and check it against z3.  Landed with the
oracle: `debug_term_bounds` (tracker vs simplex per term) and the
recursive reason-term decoder in the INVALID dump.

**Item 4 (watch layout) — CLOSED at reference parity.**  kissat's watch
is a 4-byte tagged union (31-bit ref/lit + binary tag; blocker fetched
from the clause on large-watch scans).  nixie's `Watcher` is 8 bytes of
direct arena ref + stored blocker with an AVX2 4-block filter, and
binary clauses are propagated by the BIG exclusively (no watch entries
at all — `studies/2026-09-big-authoritative-bcp.md`).  No layout gap to
close; the profiled single-load 33.6 % is inherent truth-array/arena
traffic on these instances.

**Item 3 (preset tuning) — DEFERRED**, heuristic class: needs the
pre-registered ≥10-seed matched-null protocol of `docs/BENCHMARKING.md`
(the 4.8× spread is real but a re-tune reroutes every SAT trajectory).
