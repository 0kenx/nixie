# Issue #20, first frame piece: candidate universes for set-valued state variables

**Date:** 2026-11-23
**Issue:** #20 (symbolic sets — the corpus's largest blocker class)
**Landed from:** worktree `tla-20-frames`

## What landed

`nixie-tla-check/src/frames.rs`: a **frame analysis** over the lowered
`Init`/`Next` that derives, per set-valued state variable, a candidate
**universe** — the kernel terms that could ever be members, by fixpoint:

* `U_v` starts as the elements of `Init`'s assignment (`v = rhs` or `v ∈ S`);
* every `Next` disjunct's assignment contributes its `rhs`'s elements, where
  reading a set-valued variable yields *its* universe (`v' = v \ {t}`
  inherits), enumerable existential binders are instantiated per candidate
  (a new kernel substitution, `subst_term`), and map/filter shapes
  over-approximate to their base's candidates;
* elements are **ground-evaluated and deduplicated by value** — the first
  two drafts deduplicated by pointer, and `t + 1` chains grew a universe of
  distinct spellings of few values (45 candidates for 5 values), which the
  solver paid for at every membership;
* a variable whose fixpoint outgrows the candidate budget is **not framed**:
  it keeps its opaque variable and today's honest refusal.

The encoder consults the frame exactly where the refusal used to be:
`set()`/`set_as_arena` on an opaque set-sorted variable builds the universe's
elements at that step, each guarded by `element ∈ v@k` on the **real**
variable term. The frame never decides presence — the set theory does — so
an over-approximate universe cannot invent a behaviour. What it must
guarantee is the other direction (no member missed), which the fixpoint
gives by induction over the assignment shapes; a re-entrant or
failing-to-encode element poisons the frame and restores the refusal, never
a partial list.

## Known solver limitation (measured, not hand-waved)

A transition whose added members are **arithmetic over the set's own
members** (`s' = s ∪ {t + 1}`, `t ∈ s`) yields sound universes but queries
the set theory finds hard: membership through two-plus chained
union-of-singleton steps with arithmetic inside does not converge without a
budget. Under the harness's conflict budget these are honest `Unknown`s;
unbounded they run long. The corpus's real blocked specs do not grow
arithmetically (they add/remove existing members), so this does not affect
the A/B above; it is recorded here so the next session knows the boundary.

## Step 4 (landed the same week): skolemizing existentials over symbolic set names

The corpus's biggest remaining `blocked` class after the frames pass was
`a set-valued term with no candidate list to enumerate` — 35 modules whose
quantifiers bind over sets no frame can derive a universe for, chiefly
**unconstrained `CONSTANT`s** (`Channel.tla`'s `\E d \in Data : Send(d)`).

**The design** (per the issue's step 4): extend the polarity-tracked
skolem pass (`skolemize_infinite_existentials`) with a caller-supplied set
of **symbolic set names**. A positive `\E d \in Data : P` (or a negative
`\A`) whose domain is a `Var` in that set rewrites to `c \in Data ∧ P(c)`,
the membership kept as a set-theory constraint. This is
satisfiability-exact — standard skolemization, fresh constant per
position, the polarity tracking already in the pass — not an
approximation: `∃d∈S. P` ⟺ `∃c. c∈S ∧ P(c)`.

**The names are chosen surgically**: a coarse frames pass over the
pre-skolem terms (all state variables as subjects) names what it can
frame; `quantifier_domain_names` collects the `Var` names used as
quantifier domains in the roles; the skolem set is their difference minus
the infinite four. A variable the frames pass covers keeps its
enumeration, which is stronger per witness. The precise frames pass after
inference then re-derives on the rewritten terms.

**Corpus A/B** (905 modules, both arms): no-violation 70→70, violation
20→20, undecided 31→37, blocked 194→186. All movement is forward and
per-cell accounted: Channel, ChannelTyped, Rand, powerset and the
SpecifyingSystems Channels **encode** (honest undecided); both Paxos
`Consensus` modules reach a **deadlock** verdict; the two `InnerFIFO`s
advance to a *different* named gap (`\in Seq(S)` over non-statical
elements). Zero verdict regressions.

**The boundary, honestly drawn**: a positive `\A` over an unconstrained
constant (`\A t \in TxId : …` in `KeyValueStore`'s `Init`) cannot be
skolemized — a universal has no witness — and stays declined, naming the
shape; that class needs the arena-style capacity cells Apalache uses.
And a counterexample whose witness the solver left undecided (nothing
pins the skolem to a concrete value) is **`Unknown`**, not a fabricated
violation: the independent replay could not verify a made-up witness
(`unconstrained_witness_refuses_rather_than_fabricates` pins this).

## Step 5 (landed the same week): function-domain frames — `DOMAIN` of a state function

The bag-update wall (`METHODOLOGY.md` §Bags) was the last named shape of
the `no candidate list` class inside a spec's own state: `token' = [n \in
DOMAIN token |-> …]` — a function constructor over the **symbolic domain**
of a state function.

**The design**: a function-valued state variable gets a **key universe**,
derived exactly as a set frame is — an assignment-site fixpoint over the
lowered `Init`/`Next`:

- `b' = [x \in S |-> e]` (and a recursive function over `S`) contributes
  `elements(S)`;
- `b' = [b EXCEPT ![k] = v]` inherits `b`'s keys — `EXCEPT` **keeps the
  domain**, matching both Apalache `FunExcept` rules (which copy `dom(f)`
  over "as it does not change") and TLC (which errors on a fresh key, so
  no checkable spec relies on the result);
- `b' \in [S -> T]` pins the keys to `elements(S)`.

A `DOMAIN b` in a quantifier or constructor position instantiates over the
universe, each key guarded by `k \in DOMAIN b@step` on the **real** domain
term — the same solver-mediated presence the set frames use, and sound for
the same reason (the universe may over-approximate, never miss, by
fixpoint construction).

**Encounter with the `EXCEPT` domain question.** Mid-step, a regression
test suggested `EXCEPT` at a fresh key should *extend* the domain; the
solver agreed and found a violation — but the replay's evaluator refused
("outside the domain"). Consulting the ecosystem settled it: Apalache's
both `FunExcept` rules copy the domain unchanged, and TLC errors on the
shape. The extension was reverted; the boundary is pinned by
`except_at_a_fresh_key_keeps_the_domain` (an invisible write must not
invent a domain member) and `except_update_is_visible_to_domain_quantifiers`
(an in-domain write must be visible).

**Corpus A/B** (905 modules): no-violation 70→70, violation 20→21,
undecided 37→37, blocked 186→185. The one new violation is
**`Test1305.tla`** — previously blocked at exactly this wall, now a
violation at step 1 with the trace independently replayed, and **Apalache
agrees** (`fun' = [x \in DOMAIN fun |-> fun[x] + x]` breaks `fun[1] /= 2`;
exit 12). The `no candidate list` class drops 27→24; the movers advanced
deeper into their specs. Zero verdict regressions.

**Boundary, honestly drawn**: a function over an **unconstrained
`CONSTANT`** domain (`store = [k \in Key |-> NoVal]` in `KeyValueStore`)
still declines — its keys are not derivable from assignment sites, and the
unused-binder case would need a const-array the solver's array theory does
not expose (and `KeyValueStore`'s invariant additionally needs `\A`-over-
`Key`, which has no witness). The `Bags` module's own operator chains
(`LET`-nested `(-)`, `CopiesIn`) still meet their pre-existing
type-inference limitation; the kernel shape they lower to is closed.
