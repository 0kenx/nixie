# Issue #20, first frame piece: candidate universes for set-valued state variables

**Date:** 2026-11-23
**Issue:** #20 (symbolic sets — the corpus's largest blocker class)
**Landed from:** worktree `tla-20-frames`

## What landed

`nixie-tla-check/src/frames.rs`: a **frame analysis** over the lowered
`Init`/`Next` that derives, per set-valued state variable, a candidate
**universe** — the kernel terms that could ever be members, by fixpoint:

* `U_v` starts as the elements of `Init`'s assignment (`v = rhs` or `v ∈ S`);
* every `Next` disjunct's assignment contributes its `rhs`'s elements, where
  reading a set-valued variable yields *its* universe (`v' = v \ {t}`
  inherits), enumerable existential binders are instantiated per candidate
  (a new kernel substitution, `subst_term`), and map/filter shapes
  over-approximate to their base's candidates;
* elements are **ground-evaluated and deduplicated by value** — the first
  two drafts deduplicated by pointer, and `t + 1` chains grew a universe of
  distinct spellings of few values (45 candidates for 5 values), which the
  solver paid for at every membership;
* a variable whose fixpoint outgrows the candidate budget is **not framed**:
  it keeps its opaque variable and today's honest refusal.

The encoder consults the frame exactly where the refusal used to be:
`set()`/`set_as_arena` on an opaque set-sorted variable builds the universe's
elements at that step, each guarded by `element ∈ v@k` on the **real**
variable term. The frame never decides presence — the set theory does — so
an over-approximate universe cannot invent a behaviour. What it must
guarantee is the other direction (no member missed), which the fixpoint
gives by induction over the assignment shapes; a re-entrant or
failing-to-encode element poisons the frame and restores the refusal, never
a partial list.

## Known solver limitation (measured, not hand-waved)

A transition whose added members are **arithmetic over the set's own
members** (`s' = s ∪ {t + 1}`, `t ∈ s`) yields sound universes but queries
the set theory finds hard: membership through two-plus chained
union-of-singleton steps with arithmetic inside does not converge without a
budget. Under the harness's conflict budget these are honest `Unknown`s;
unbounded they run long. The corpus's real blocked specs do not grow
arithmetically (they add/remove existing members), so this does not affect
the A/B above; it is recorded here so the next session knows the boundary.
